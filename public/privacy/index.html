Конфиденциальность BAIagent Director

Редакция от 29 октября 2026 г.

Этот документ описывает обработку данных в приложении BAIagent Director для Windows и в веб-аудите на baiagent.ru/xray/. Оператор — Баланов Антон Николаевич.

1. Исследование открытых данных

По указанному вами адресу сайта приложение запрашивает открытые страницы компании и внешние упоминания. Для поиска могут использоваться Bing, Lumy, Википедия и Google Новости. Эти сервисы и посещаемые сайты получают сетевые запросы и стандартные технические данные, включая IP-адрес, и обрабатывают их по собственным правилам.

Не указывайте закрытые адреса, пароли, персональные данные и сведения, которые нельзя передавать внешним сервисам.

2. Локальные документы и ИИ в Windows

  • Документы обрабатываются только после явного выбора файла или папки и отдельного подтверждения чтения папки.
  • Содержимое выбранных документов используется в локальном контексте модели и не отправляется оператору или в облачную модель через приложение.
  • Диалог выполняется через локальную Ollama на 127.0.0.1 либо через встроенную модель на устройстве.
  • При первом использовании встроенной модели приложение может загрузить её файлы из каталога Hugging Face. Выбранные документы для этой загрузки не передаются.
  • План пилота записывается только в файл и папку, которые вы выбрали.

3. Веб-аудит

В веб-версии указанный публичный URL передаётся серверу baiagent.ru для выполнения исследования. Веб-версия не принимает локальные документы. Хостинг и внешние источники могут сохранять технические журналы, необходимые для работы и защиты сервиса.

4. Учётные записи и аналитика

Для базового использования приложения учётная запись не требуется. В исходном коде приложения нет рекламных идентификаторов или сторонних систем поведенческой аналитики. Microsoft Store может предоставлять оператору обезличенную статистику установок и сбоев по собственным правилам.

5. Внешние ссылки

Переходы к источникам, каталогам решений и другим сайтам выполняются по вашему действию. Их обработка данных регулируется политиками соответствующих владельцев.

6. Ваш выбор и обращения

Вы можете не запускать исследование, не выбирать документы, отозвать разрешение на чтение папки до подтверждения и удалить сохранённые локальные файлы средствами Windows. По вопросам конфиденциальности и удаления данных, переданных непосредственно оператору, можно обратиться через balanov.pro.
