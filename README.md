# BAIagent — ИИ-советник для бизнеса

**Бесплатный ИИ-советник: компания, рынок, локальные документы и проверяемый следующий шаг.**

Укажите сайт компании. Советник исследует открытые страницы и внешние упоминания, отделяет факты от гипотез, показывает источники и помогает сформировать измеримый пилот. Windows-версия дополнительно работает с выбранными документами и локальной моделью.

## Возможности

- Первичное знакомство с компанией по одному сайту, без длинной анкеты.
- Исследование товаров, услуг, цен, конкурентов, отзывов и рыночных сигналов с адресами источников.
- Причинные гипотезы: наблюдение → механизм → действие → способ проверки.
- Своя гипотеза кнопкой или командой в диалоге — с фактическим сохранением, выбором и построением плана.
- Конкретный пилот с метрикой, неизвестными и границами, а не обещание автоматической прибыли.
- Самостоятельное внедрение внутри советника: этапы, ориентиры сроков, владельцы, формула бюджета и критерий остановки.
- Локальный диалог и документы в Windows: TXT, Markdown, CSV, JSON, PDF и DOCX.
- Qwen через существующую локальную Ollama или загружаемая модель Qwen3-4B — без обязательного облачного API-ключа.
- Подбор решения из проверенного каталога BAIagent после определения задачи. Справочные рекомендации не равны уже внедрённому автономному агенту.
- Режимы BAIagent, веб-аудита и расширенного enterprise-аудита Balanov.PRO на общей кодовой базе.

## Границы продукта

Это советник, а не автономный сотрудник: он не выполняет операции в CRM сам. Рекомендации остаются гипотезами до проверки реальными данными. Цитата подтверждает наличие текста в источнике, но не истинность утверждения источника или коммерческую ценность идеи.

Свежий рыночный сбор требует интернет. Локальный диалог и сохранённые материалы могут использоваться без сети. Веб-версия не заявляет локальный запуск Qwen в браузере.

## Разработка

Требуется Node.js 24 и npm.

```bash
npm ci
npm run electron:dev
```

Проверки и сборки:

```bash
npm test
npm run build
npm run build:xray
npm run build:advisor
npm run build:enterprise
```

Пройдены **362 автотеста** в 28 файлах и все пять перечисленных команд сборки/проверки. Дополнительно проверены локальный оркестратор Qwen3 14B и семь desktop-сценариев: приветствие, контекстная рекомендация, создание и выбор собственной гипотезы, план, пилот и самостоятельное внедрение. Результат проверки собранного Windows-приложения фиксируется отдельно. Для desktop, веб- и enterprise-режимов используются разные точки входа и серверные контуры; не следует считать их возможности взаимозаменяемыми.

Пакеты desktop:

```bash
npm run dist:win
npm run dist:linux  # на Linux
npm run dist:mac    # на macOS
```

Workflow `.github/workflows/release.yml` отдельно собирает Director и Balanov.PRO Enterprise для Windows, а также Linux- и macOS-пакеты Director на соответствующих runners. Сборка не публикуется автоматически внутри упаковщика: сначала проверяется наличие артефактов. Наличие workflow не означает, что macOS-пакет нотаризован или все платформы проверены вручную.

## Веб-развёртывание

```bash
npm run build:xray
```

Содержимое `dist/` развёртывается в `/xray/` на PHP 8.1+ с cURL, DOM и SimpleXML. Браузер обращается к `/xray/api/research.php`; облачный ключ модели для этого маршрута не нужен.

Enterprise-режим собирается через `npm run build:enterprise` в `dist-enterprise/` с базовым путём `/ai-audit/`.

## Структура

```text
src/             React-интерфейс и результаты аудита
electron/        изолированный desktop-контур, локальные файлы и Qwen
shared/          исследования, доказательства, рекомендации и пилоты
public/api/      PHP-контур публичного исследования
scripts/         сборка и проверки
tests/           автоматические регрессионные проверки
android/         нативный Android-прототип
docs/images/     изображения документации
```
