# BAIagent Director 0.8.1

Бесплатный ИИ-советник для бизнеса: исследование компании и рынка по открытым источникам, локальные документы и проверяемый следующий шаг.

## Включено

- Первичный аудит компании по одному сайту.
- Исследование товаров, услуг, конкурентов, отзывов и рыночных сигналов с адресами источников.
- Причинные гипотезы, явные неизвестные и пилот с метрикой проверки.
- Windows-версия с выбранными локальными документами и диалогом через существующую Ollama или загружаемую Qwen3-4B.
- Режимы BAIagent, веб-аудита и расширенного enterprise-аудита Balanov.PRO на общей кодовой базе.
- Подбор решений из каталога BAIagent после определения задачи.

## Проверено перед подготовкой релиза

- 161 автоматический тест в 14 файлах.
- Команды `npm run build`, `npm run build:xray`, `npm run build:advisor` и `npm run build:enterprise`.
- Публичный Windows-установщик скачан с `baiagent.ru`; размер и SHA-256 сверены с опубликованным `current.json`.

## Ограничения

Установщик не имеет Authenticode-подписи: Windows может показать предупреждение о неизвестном издателе или SmartScreen. Рекомендации являются гипотезами, а не гарантией коммерческого результата. Для свежего исследования нужен интернет. Наличие кроссплатформенного workflow не означает ручную проверку, подпись или нотаризацию пакетов macOS и Linux в этом релизе.
