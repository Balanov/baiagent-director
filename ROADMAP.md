# Roadmap

## v0.2 — one-button director

- One website field and automatic research.
- Local Qwen through Ollama or automatic embedded Qwen3 4B.
- Verbatim evidence checks and unsupported-number rejection.
- Optional local documents on desktop.
- Downloadable 14-day pilot plan.
- Responsive web entry point and Windows installer.
- Native CI build matrix for Windows, Linux and macOS.

## Next product milestones

### Activation

- Measure first-run completion, model-download completion and time to first useful result.
- Add resumable model download status and clearer disk/RAM diagnostics.
- Improve opportunity ranking with user-confirmed process evidence.
- Add one-click handoff from an accepted pilot into the relevant BAIagent agent.

### Trust

- Claim/evidence entailment checks in addition to verbatim quote matching.
- Source-date and source-type display.
- Signed Windows releases and notarized macOS releases.
- Reproducible release checksums and provenance attestations.
- Edge rate limits and public endpoint abuse monitoring.

### Distribution

- Publish native CI artifacts after matrix verification.
- Prepare honest listings for GitHub, Uneed, Product Hunt and relevant directories.
- Add localized English onboarding while preserving the same evidence rules.
- Collect opt-in user feedback and publish only verified adoption metrics.

No download counts, stars, forks, revenue or customer outcomes are assumed in this roadmap; they must come from observable data.
