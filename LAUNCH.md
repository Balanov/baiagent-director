## Product Hunt / Uneed

**Name:** BAIagent Director

**Tagline:** One website. One button. A local AI director with evidence.

**First comment / description:**

Most business AI tools start with a questionnaire, an API key and a long setup. BAIagent Director starts with one website field.

The desktop app researches public pages, runs Qwen locally and proposes a focused pilot with exact source quotes, explicit unknowns and a way to measure the result. It rejects fabricated citations and unsupported numbers instead of presenting them as facts.

It is also the free entry point into the broader BAIagent ecosystem: if the pilot makes sense, it can become a real agent workflow rather than another disconnected demo.

- No API keys
- Local model inference
- Optional internal documents on desktop
- Checkable sources and a downloadable pilot plan
- Open source

We would especially value feedback on first-run activation and the quality of the evidence links. Recommendations are hypotheses to test, not promised savings.

## Hacker News — Show HN draft

**Title:** Show HN: A local AI director that turns one company URL into an evidence-linked pilot

I built a small open-source Electron app around local Qwen. You enter a company website; it reads public pages and proposes a limited pilot rather than a generic AI strategy.

The part I care about most is the verification layer: exact quotes must exist in the retrieved source, unrelated search results are filtered, and unsupported numbers are rejected. The UI labels opportunities as hypotheses and shows unknowns next to the recommendation.

It uses an existing local Ollama Qwen when available or downloads Qwen3 4B on first run. Public research needs internet; model inference and optional internal-document analysis stay local.

I would appreciate technical feedback on citation verification, first-run UX and native packaging. The web demo uses a deterministic evidence-based fallback, not browser-based Qwen.
